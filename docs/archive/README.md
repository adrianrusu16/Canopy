# Documentation Archive

These files preserve Canopy's design and implementation history. They are not
maintained operational guidance and may contain obsolete paths, versions,
status statements, or planned behavior.

## Designs

[`designs/`](designs/) contains decision records and approved designs from
completed or superseded work.

## Implementation Plans

[`plans/`](plans/) contains task-level execution plans. Use the maintained
documentation index for current behavior and procedures.
